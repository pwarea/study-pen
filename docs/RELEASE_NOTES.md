# Study Pen 0.1.2

Study Pen is a portable screen annotation app for 64-bit Windows 10 and 11.

- Toolbar icons use antialiased edges at common Windows display scales.
- The horizontal and vertical toolbars keep their icons upright and aligned with the controls.
- Radial selections apply when you release the shortcut, so you can move between choices while holding.
- Release in the center or press Esc to cancel. Hold over Colors to open the color wheel, then return to its center briefly to go back.

Automatic startup updates show progress before the toolbar opens and keep your saved settings. Choose **Skip for now** while checking or downloading, or switch off **Automatic updates at startup** in **Settings → General**.

If you use 0.1.0, choose **Install update** under **Settings → General** to upgrade this time. Automatic startup installation applies from 0.1.1 onward.

Extract the portable ZIP into a writable folder and run `study-pen.exe`.
