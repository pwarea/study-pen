# Study Pen 0.1.0

Study Pen is a portable screen annotation app for 64-bit Windows 10 and 11.

- Draw above your desktop and switch to the cursor without clearing the ink.
- Use the glass toolbar horizontally or dock it vertically.
- Erase whole strokes or parts of a stroke, undo gestures, and save two colors.
- Customize global shortcuts and enable the optional radial menu.
- Open Study Pen from the desktop or Start after the first launch.
- Check GitHub for updates on startup and choose when to install them.

Extract the portable ZIP into a writable folder and run `study-pen.exe`.
