# Study Pen 0.1.1

Study Pen is a portable screen annotation app for 64-bit Windows 10 and 11.

- A startup window shows update progress before the toolbar opens.
- Study Pen automatically installs a verified portable update from its release repository and restarts with your saved settings.
- **Skip for now** opens the installed version while Study Pen is checking or downloading. Use **Settings → General → Automatic updates at startup** to opt out.

If you use 0.1.0, choose **Install update** under **Settings → General** to upgrade this time. Automatic startup installation applies from 0.1.1 onward.

Extract the portable ZIP into a writable folder and run `study-pen.exe`.
