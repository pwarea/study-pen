# Study Pen 0.1.2

- Check for updates from Settings → General, even with automatic checks turned off.
- Manual updates show download and installation progress and can be canceled before installation.
- The startup updater gives you more time to skip a download before installation.
- Sharper toolbar icons and more reliable radial menu selection.

Extract the portable ZIP into a writable folder and run study-pen.exe. Existing portable copies save your settings during an update.
