# Study Pen 0.2.0

- Choose Liquid Glass or the translucent blue-gradient Liquid Air toolbar theme.
- Customize the toolbar in Settings: add, remove and reorder tools, show compact tool names, or reset the default tool list and order.
- Add Shapes to draw rectangles, ellipses, lines, arrows and triangles. Fill closed shape objects with the selected color; erasing and Undo also work with shapes.
- Add a movable, rotatable ruler for straight pen strokes. Click Rotate for 15° steps, hold Shift for precise rotation, or click the degree readout to reset to 0.0°.
- Sharper toolbar and ruler text, clearer drag handles, smoother color controls, and more reliable left-edge docking.
- Automatic startup updates remain enabled by default. Skip checking or downloading, or turn them off in Settings. Manual checks and verified installation remain available with progress and cancellation before installation begins.

Extract the portable ZIP into a writable folder and run `study-pen.exe`. Verified in-app updates preserve existing preferences. Windows 10 and 11, x86-64.
