# Study Pen 0.2.2

- Mouse and pen now share one toolbar switch by default. Enable **Separate Mouse and Pen** in **Settings → Toolbar** to use individual buttons.
- The last toolbar controls stay in the order **Settings → Hide toolbar → Quit Study Pen**. Settings and Quit are required; Hide toolbar is optional.
- The pen pointer uses a native fountain nib and briefly enlarges with a smooth animation during very fast movement, making it easier to locate.
- Added drawing guards for stale gestures, synthetic pointer movement, capture loss and cancellation to reduce unwanted connecting lines.

Extract the portable ZIP into a writable folder and run `study-pen.exe`. Verified in-app updates preserve existing preferences. Windows 10 and 11, x86-64.
