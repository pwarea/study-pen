# Radial menu

The optional radial menu provides access to tools while the toolbar is hidden. Its global shortcut is **unassigned by default**. Open Settings → Shortcuts and assign **Radial menu** before using it. Existing shortcuts keep their assignments.

Hold the assigned shortcut to show a circular menu at the center of the monitor containing the pointer. It uses the full monitor bounds. The pointer moves to the menu's neutral center so opening it does not select an action. Move outward toward a sector and keep the pointer there briefly to choose it; no click is needed.

| Position | Action |
| --- | --- |
| Left | Toggle between mouse / desktop interaction and the pen |
| Right | Clear all ink |
| Top | Select the object eraser |
| Bottom | Open the color wheel |

The color wheel offers 12 preset colors and the primary and secondary color slots. The current primary color is highlighted. Hover over a swatch to set the primary color; the secondary color stays as saved. The wheel uses the same two color slots as the normal color panel.

Opening Colors moves the pointer to the center again before selection. A short stable hover selects a swatch. The center remains neutral, so a quick pass through it does not trigger a selection.

Each hold applies one tool action or one color. The selected item stays highlighted until release, so keeping the pointer over Clear or the mouse/pen sector does not repeat that command. Release and hold again to make another selection. The left sector returns any active ink tool to mouse/desktop interaction; if drawing is inactive, it selects the pen.

Release the shortcut's main key to close the menu. Its modifier keys may be released first. The pointer remains at its current position after closing.

Colors continue to use Study Pen's saved preferences. The full color panel remains available for arbitrary HEX/RGB values. The radial menu's shortcut uses the same validation and per-action availability checks as the other global shortcuts.
