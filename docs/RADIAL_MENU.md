# Radial menu

The optional radial menu provides access to tools while the toolbar is hidden. Its global shortcut is **unassigned by default**. Open Settings → Shortcuts and assign **Radial menu** before using it. Existing shortcuts keep their assignments.

Hold the assigned shortcut to show a circular menu at the center of the monitor containing the pointer. It uses the full monitor bounds. The pointer moves to the menu's neutral center. Move outward to highlight a sector, then release the shortcut's main key to apply it. Move between sectors while holding to reconsider your choice.

| Position | Action |
| --- | --- |
| Left | Toggle between mouse / desktop interaction and the pen |
| Right | Clear all ink |
| Top | Select the object eraser |
| Bottom | Open the color wheel |

The color wheel offers 12 preset colors and the primary and secondary color slots. The current primary color is highlighted. Move over a swatch and release the shortcut's main key to set the primary color. The secondary color stays as saved. The wheel uses the same two color slots as the normal color panel.

Keep the pointer over Colors briefly while holding the shortcut to open the color wheel. The pointer moves to its neutral center. After moving out to the swatches, you can return to the center and hold there briefly to go back to the tool menu. The center shows **Back** when this is available.

Each hold applies at most one tool action or one color on release. Releasing in the center, between sectors, or beyond the wheel's outer tolerance cancels the choice. A small allowance outside the painted ring accommodates overshoot. Press Esc to cancel while holding. The left sector returns any active ink tool to mouse/desktop interaction; if drawing is inactive, it selects the pen.

The modifier keys may be released before the shortcut's main key. The pointer remains at its current position after closing. Mouse clicks are unnecessary.

Colors continue to use Study Pen's saved preferences. The full color panel remains available for arbitrary HEX/RGB values. The radial menu's shortcut uses the same validation and per-action availability checks as the other global shortcuts.
